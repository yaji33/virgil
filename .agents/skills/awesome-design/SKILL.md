# Awesome Design Skill

## Goals

Create interfaces that feel:
- Intentional
- Calm under pressure (especially important for risk/trading tools)
- Professional and trustworthy
- Delightful in the details without being distracting

## Key Practices

- Every screen should have a clear primary action or primary information hierarchy
- Reduce cognitive load for the decision flow
- Use progressive disclosure for advanced mandate settings
- Micro-copy should be precise and human
- Empty, loading, and error states are part of the design system — treat them with care

## Specific to Vigil

The most important UI surface is the **Decision Card**:
- Clear proposal summary
- Risk agent results (compact but complete)
- Final decision with reasons
- Link to full audit entry

Everything else supports this flow.
